# TriEmulate website

Static site. No build step. Upload the contents of this folder to the root of the repo and deploy as before.

## Recent changes

- New logo in the nav and footer of every page, the browser tab icon, phone home-screen icon, social share image and structured data.
- Logo is larger, with the wordmark set closer to the mark. Hovering it plays one turn of the brand animation (off for reduced motion).
- Site blue matches the logo (#2563EB); navy (#0A1C36) for text and the footer.
- Founder card on the home page now uses the headshot; signature removed; footer credit is the name only.
- 404 page shows the animated mark.

index.html, method.html, output.html, boundaries.html, watch.html, 404.html
favicon.ico, site.webmanifest, sitemap.xml

assets/img/                  Founder headshot, 4:5, at 600 / 900 / 1200 px in JPG and WebP
assets/css/site.css          Design system
assets/js/                   site.js, journey.js, strands.js, flow.js, cohort.js
assets/logo/svg/ and png/    Logo files, transparent, light and on-dark versions, plus app icons

Keep from the previous deploy (not included here): robots.txt and assets/video/.
